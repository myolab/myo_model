# Joint Name Abbreviations

This document provides the full anatomical names for abbreviated joint names used in the MyoSkeleton model.

## Spinal Joints

| Abbreviation | Full Name |
|--------------|-----------|
| l5_s1 | Lumbosacral joint (5th Lumbar - 1st Sacral vertebrae) |
| l4_l5 | 4th-5th Lumbar vertebrae joint |
| l3_l4 | 3rd-4th Lumbar vertebrae joint |
| l2_l3 | 2nd-3rd Lumbar vertebrae joint |
| l1_l2 | 1st-2nd Lumbar vertebrae joint |
| t12_l1 | Thoracolumbar joint (12th Thoracic - 1st Lumbar vertebrae) |

## Cervical (Neck) Joints

| Abbreviation | Full Name |
|--------------|-----------|
| c7_t1 | Cervicothoracic joint (7th Cervical - 1st Thoracic vertebrae) |
| c6_c7 | 6th-7th Cervical vertebrae joint |
| c5_c6 | 5th-6th Cervical vertebrae joint |
| c4_c5 | 4th-5th Cervical vertebrae joint |
| c3_c4 | 3rd-4th Cervical vertebrae joint |
| c2_c3 | 2nd-3rd Cervical vertebrae joint (Axis-C3) |
| c1_c2 | Atlantoaxial joint (Atlas-Axis, 1st-2nd Cervical vertebrae) |
| occ_c1 | Atlanto-occipital joint (Occiput-Atlas, Skull-1st Cervical vertebra) |

## Upper Limb Joints

### Shoulder Girdle & Arm

| Abbreviation | Full Name |
|--------------|-----------|
| clav | Clavicle (Collarbone) |
| clav_prot | Clavicle protraction/retraction |
| clav_elev | Clavicle elevation/depression |
| shoulder | Glenohumeral joint (Shoulder ball-and-socket joint) |
| elbow | Elbow joint (Humeroulnar and Humeroradial joints) |

### Hand & Wrist

| Abbreviation | Full Name |
|--------------|-----------|
| wrist_pron | Wrist pronation/supination (Radioulnar joint) |
| wrist_devi | Wrist radial/ulnar deviation (Radiocarpal joint) |
| wrist_flex | Wrist flexion/extension (Radiocarpal joint) |
| cmc | Carpometacarpal joint (Thumb base joint) |
| mp | Metacarpophalangeal joint (Thumb knuckle) |
| ip | Interphalangeal joint (Thumb tip joint) |
| mcp2-5 | Metacarpophalangeal joints (Finger knuckles, digits 2-5) |
| pm2-5 | Proximal interphalangeal joints (Middle finger joints, digits 2-5) |
| md2-5 | Distal interphalangeal joints (Finger tip joints, digits 2-5) |

### Hip & Knee

| Abbreviation | Full Name |

| knee | Knee joint (Tibiofemoral joint) |
| patella | Patella (Kneecap) |

### Foot & Ankle

| Abbreviation | Full Name |
|--------------|-----------|
| ankle | Talocrural joint (Ankle joint) |
| subtal | Subtalar joint (Talocalcaneal joint) |
| mtp | Metatarsophalangeal joint (Ball of foot joint) |
